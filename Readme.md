
# Browser Navigation System Using Stack in C

## Project Description
A menu-driven C program that simulates browser navigation using the stack data structure.

## Features
- Visit a new webpage
- Go Back to a previous webpage
- Go Forward to the next webpage
- Display navigation history
- Handle empty stack conditions

## Data Structures Used
- Back Stack: Stores previously visited pages.
- Forward Stack: Stores pages available for forward navigation.

## Concepts Used
- Stack (LIFO)
- Push and Pop operations
- Arrays and strings
- Functions in C

## Programming Language
C

## How to Run
Compile using GCC:

gcc browser_navigation.c -o browser_navigation

Run on Linux:

./browser_navigation

## Conclusion
This project demonstrates how stacks can be used to manage browser navigation history.
